# Mi diario secreto

Diario de ánimo y actividades, solo para uso personal. Hecho con Kotlin y Jetpack Compose.

## Qué incluye (versión 0.1)
- Registro de ánimo (5 niveles), actividades y nota.
- Historial de entradas.
- PIN de 4 a 6 números y desbloqueo con huella.
- Copia de seguridad cifrada (AES-256-GCM) en una carpeta que eliges tú. La app nunca borra copias anteriores.
- Tema oscuro (principal), claro o del sistema.
- Los datos se quedan en el teléfono. Sin cuentas, sin servidor.

## Cómo conseguir el APK
Cada vez que subes cambios a la rama `main`, GitHub compila la app.
Entra en la pestaña **Actions**, abre la última ejecución y descarga **diario-apk**.
